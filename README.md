# Лабораторная работа №1

- Создание, просмотр, изменение и удаление городов;
- Таблица с пагинацией, фильтрацией и сортировкой;
- При удалении координат или губернатора связанные города переподключаются к другому объекту;
- Изменения сразу видны всем открытым клиентам;
- Специальные операции: удаление по климату, подсчёт по высоте, поиск по подстроке, переселение населения;
- Регистрация и вход.

## Стек

- `Java 21`: язык бэкенда
- `Payara 7`: сервер приложений
- `Jakarta EE 11`: платформа, которую предоставляет сервер
- `JAX-RS`: REST API
- `JSON-B`: преобразование объектов в JSON и обратно
- `CDI-beans`: внедрение зависимостей и транзакции
- `JPA-EclipseLink`: ORM, отображение сущностей на таблицы
- `Bean Validation`: ограничения полей на уровне ORM
- `PostgreSQL`: хранение данных
- `WebSocket`: обновления в реальном времени
- `HTML`: фронтенд
- `JavaScript`: скрипты фронтенда, запросы через `fetch`
- `Lombok`: генерация геттеров и сеттеров
- `Gradle`: сборка проекта
- `Docker`: локальный запуск PostgreSQL

## Структура

- `entity`: сущности базы данных 
- `model`: классы для хранения данных
- `mapper`: мапперы даных 
- `repository`: запросы к базе данных 
- `service`: бизнес-логика и транзакции
- `validator`: проверка входных данных
- `exception`: исключения приложения
- `point`: REST-ресурсы и фильтр авторизации
- `event`: событие об изменении данных
- `websocket`: рассылка изменений

## Запуск

Нужны Java 21, Docker и Payara 7, распакованный в папку `payara7/` в корне проекта.

```sh
docker-compose up -d
./gradlew build
./payara7/bin/asadmin start-domain
./payara7/bin/asadmin deploy --force=true --contextroot /is_lab_1 build/libs/is_lab_1.war
```

Таблицы в базе создаются автоматически при первом деплое.

```sh
./payara7/bin/asadmin stop-domain
docker-compose down
```
